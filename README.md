# FlyRank-AI — BackendAssignment

Simple Node.js/Express backend for the BackendAssignment.

## Structure

- `BackendAssignment/` — project folder containing `server.js` and `package.json`.

## Run locally

1. Install dependencies:

```bash
cd BackendAssignment
npm install
```

2. Start the server:

```bash
npm start
```

3. Open http://localhost:3000/ or http://localhost:3000/about

## Notes

- `server.js` exposes two simple endpoints: `/` and `/about`.
- This README was added and the repository prepared for pushing to GitHub.
